# 🌐 Amnendra Tomar's Portfolio

Welcome to my personal portfolio website! This project showcases my journey as a web developer, featuring my skills, projects, and design philosophy. Built with modern frontend technologies, it reflects my passion for clean design, responsive layouts, and interactive user experiences.

## 🚀 Live Demo

Check out the live site here: [Visit Portfolio](https://amnendratomar.github.io/Portfolio)

## 📌 Features

- ✨ **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- 🎨 **Clean UI/UX** – Minimalist layout with intuitive navigation.
- 🧠 **About Me Section** – Highlights my background, interests, and goals.
- 🛠️ **Projects Showcase** – Displays key projects with links and descriptions.
- 📫 **Contact Form** – Allows visitors to reach out directly.
